# Lista para rescatar los originales (sin volver a descargar millones de registros)

1. Entrar al Google Colab original con la cuenta que lo creó.
2. Descargar desde `Archivo > Descargar > Descargar .ipynb`.
3. Localizar el archivo `muestra_historica_bts.parquet` en el panel Archivos de Colab. Si aún existe, descargar o copiar a Drive. Los datos bajo `/content/` pueden desaparecer tras reinicio.
4. Revisar Google Drive de la cuenta real, carpeta `Colab Notebooks` y `Mi unidad`, buscando `proyecto_retrasos`, `vuelos_clima`, archivos `.ipynb` y `.parquet`.
5. Descargar el PDF de rúbrica desde su adjunto original en este chat.
6. Pedir a cualquier integrante la URL de GitHub del equipo (no confundir con el repositorio externo de Alura).
7. Registrar la URL de Databricks y los nombres de catálogo/esquemas/tablas que existan. No compartir contraseñas, PATs o secretos.
8. Adjuntar al nuevo chat el paquete `PAQUETE_TRANSFERENCIA_VUELOS.zip` + PDF original + Colab original + URL GitHub del equipo.

**No hay pruebas de que el repositorio GitHub o las tablas Databricks ya existan.**
